# Relevant information for this fork

This is a fork containing only the code for the module about machine learning of TTC, avoiding all dependencies on ROS.

The files with the Deeplabv3 attempts are "pattern_segmentation.py" and "deeplabv3.py". The U-Net from scratch is in "unet.py". The U-Net with the pre-trained ResNet50 is in "unet_resnet.py" (for both frozen and unfrozen parameters).
